# 법무법인 정도

백산 작가의 웹소설 **《너희들은 변호됐다》** 속 법무법인 '정도'를 웹사이트로 구현한 팬 페이지입니다.

🔗 https://nomadotaku999.github.io/you-guys-were-defended/

## 안내

- 이 사이트는 개인이 만든 비공식 팬 페이지이며, 원작자 및 연재처와 관련이 없습니다.
- 법무법인 '정도'와 구성원, 사건, 의뢰인 후기, 언론 보도 등은 모두 원작을 바탕으로 하거나 새로 지어낸 허구입니다. 실제 법무법인이 아니며, 법률 상담을 받을 수 없습니다.
- 원작 《너희들은 변호됐다》의 모든 권리는 백산 작가에게 있습니다.
